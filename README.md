# MCP Observatory

> [!WARNING]
> 🚧 **Under construction**
>
> MCP Observatory is in early development. The project is being actively built and is not ready for general use yet.

MCP Observatory is an open-source project for investigating and understanding failure behavior across Model Context Protocol (MCP) implementations.

The project will build on [MCP Failure Lab](https://github.com/anilloutombam/mcp-failure-lab) to explore test runs, evidence, compatibility findings, and implementation behavior through a structured interface.

## Status

Initial project setup.

## Tech Stack

- Next.js
- TypeScript

More components will be added as the project develops.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Related Project

[MCP Failure Lab](https://github.com/anilloutombam/mcp-failure-lab) provides deterministic failure injection and resilience testing for MCP clients and servers.
